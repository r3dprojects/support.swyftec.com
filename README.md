## What this repo is

This repository is the **public issue tracker** for [swyftec.com](https://swyftec.com). It is intentionally code-free — the platform source is proprietary. This is how we keep the conversation with our users open and structured.

**File a bug, request a feature, or ask a question** using the links below.

---

## About swyftec

swyftec is the platform layer behind [swyftpay.now](https://swyftpay.now) — providing the storefront, merchant administration, identity management, and shared infrastructure that all swyftec products run on top of.

Merchants use swyftec to manage their business profile, configure their payment terminal, set up custom domain storefronts, and access analytics. The platform is designed for micro-merchants but built to scale.

## Why no source code here?

This repo exists for public conversation. swyftec source is closed. What is open:

- Your ability to report bugs, request features, and ask questions
- Our responses, decisions, and reasoning in issue threads
- The documentation and templates in this repo (licensed [CC-BY-4.0](LICENSE))

The platform source lives in a private repository. This is a deliberate boundary, not an oversight.
